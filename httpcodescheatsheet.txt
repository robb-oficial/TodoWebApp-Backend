Here is a comprehensive, no-fluff HTTP Status Code Cheat Sheet, grouped by category. 

**The Golden Rule:** 
**1xx** = Hold on | **2xx** = Here you go | **3xx** = Go over there | **4xx** = You messed up | **5xx** = I messed up

---

### 1xx Informational (Request Received, Continuing)
*Used rarely in final responses; mostly for debugging.*

| Code | Name | Meaning |
| :--- | :--- | :--- |
| **100** | Continue | Safe to send the request body (used for large uploads). |
| **101** | Switching Protocols | Server agrees to upgrade to a different protocol (e.g., WebSockets). |
| **102** | Processing | Server is working on the request but hasn't finished (WebDAV). |

---

### 2xx Success (The Good Ones)
*The request was received, understood, and accepted.*

| Code | Name | Meaning |
| :--- | :--- | :--- |
| **200** | OK | The standard success. GET/PUT/PATCH returned successfully. |
| **201** | Created | A new resource was successfully created (usually after a POST/PUT). |
| **202** | Accepted | Request accepted for processing, but not completed yet (async). |
| **203** | Non-Authoritative Info | Returned metadata from a proxy, not the origin server. |
| **204** | **No Content** | Success, but **NO BODY** is returned in the response. (Great for DELETE or update forms). |
| **205** | Reset Content | Tells the client to clear the form/view that sent the request. |
| **206** | Partial Content | Returning only a chunk of data (used for resumable downloads/streaming). |

---

### 3xx Redirection (Go Elsewhere)
*The client must take additional action to complete the request.*

| Code | Name | Meaning |
| :--- | :--- | :--- |
| **300** | Multiple Choices | Link list; user can choose a representation. |
| **301** | **Moved Permanently** | The resource is **permanently** at a new URL. Update your bookmarks/links. (Cacheable). |
| **302** | Found (Moved Temporarily) | The resource is temporarily at a different URL. Use the *same* HTTP method. |
| **303** | See Other | Redirect to a different URL using **GET** (used after POST to prevent duplicate submissions). |
| **304** | **Not Modified** | The resource hasn't changed since the last request. Use your cached version. |
| **307** | Temporary Redirect | Same as 302, but **strictly** maintains the same HTTP method (e.g., POST stays POST). |
| **308** | Permanent Redirect | Same as 301, but **strictly** maintains the same HTTP method. |

---

### 4xx Client Errors (You Broke It)
*The request contains bad syntax or cannot be fulfilled by the client.*

| Code | Name | Meaning |
| :--- | :--- | :--- |
| **400** | **Bad Request** | The server cannot process the request due to malformed syntax (e.g., invalid JSON). |
| **401** | **Unauthorized** | You are not authenticated. Please log in (or provide valid API keys). |
| **402** | Payment Required | Reserved for future use (digital payment systems). |
| **403** | **Forbidden** | You are authenticated, but you do not have permission to access this resource. |
| **404** | **Not Found** | The requested resource could not be found on the server. |
| **405** | Method Not Allowed | The HTTP method (e.g., DELETE) is not supported for this endpoint. |
| **406** | Not Acceptable | The server cannot generate content matching the `Accept` headers sent. |
| **407** | Proxy Auth Required | You must authenticate with a proxy first. |
| **408** | Request Timeout | The server timed out waiting for the client to send the full request. |
| **409** | **Conflict** | The request conflicts with the current server state (e.g., editing a stale version of a record). |
| **410** | Gone | The resource is permanently gone and no forwarding address is known. |
| **411** | Length Required | Missing `Content-Length` header. |
| **413** | Payload Too Large | The request body is too large for the server to handle. |
| **414** | URI Too Long | The URL is too long (usually due to excessive query parameters). |
| **415** | Unsupported Media Type | The server doesn't support the `Content-Type` sent (e.g., sending XML when it expects JSON). |
| **416** | Range Not Satisfiable | Requested byte range is invalid. |
| **418** | **I'm a teapot** | *April Fools' joke.* Server refuses to brew coffee because it is a teapot. |
| **422** | Unprocessable Entity | The syntax is correct, but the semantic meaning fails validation (e.g., email format is wrong). |
| **429** | **Too Many Requests** | You are being rate-limited. Slow down! (Check the `Retry-After` header). |
| **431** | Header Too Large | The request headers are too big. |
| **451** | Unavailable For Legal | Blocked for legal reasons (e.g., DMCA or GDPR takedown). |

---

### 5xx Server Errors (The Server Broke It)
*The server failed to fulfill a valid request.*

| Code | Name | Meaning |
| :--- | :--- | :--- |
| **500** | **Internal Server Error** | The generic "catch-all" error. The server crashed or hit an unhandled exception. |
| **501** | Not Implemented | The server does not support the functionality required to fulfill the request. |
| **502** | **Bad Gateway** | The server (acting as a proxy/gateway) received an invalid response from the upstream server (e.g., Nginx can't talk to PHP-FPM). |
| **503** | **Service Unavailable** | The server is overloaded or undergoing maintenance. It is temporarily down. |
| **504** | **Gateway Timeout** | The server (acting as a proxy) did not receive a response from the upstream server in time. |
| **505** | HTTP Version Not Supported | The server does not support the HTTP protocol version used. |
| **507** | Insufficient Storage | The server is out of disk space (WebDAV). |
| **508** | Loop Detected | The server detected an infinite loop while processing the request. |
| **511** | Network Auth Required | You must log in to the network (captive portal) before accessing the internet. |

---

**⭐ Pro Developer Tip:** 
If you are designing an API, **stick to the classics**. Use `200` for successful GETs, `201` for successful POSTs, `204` for successful DELETEs, `400` for validation errors, `401` for missing logins, `403` for missing permissions, `404` for bad URLs, and `429` for rate limiting. Never use `418` in production unless you want a very confused on-call engineer at 3 AM!
